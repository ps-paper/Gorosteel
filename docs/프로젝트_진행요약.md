## 3. 주제 선정 경위

### 3-1. 처음 검토: 원심 공기압축기 + OID 데이터 (보류)

- **OID(Open Industrial Data):** Aker BP 북해 Valhall 플랫폼의 1단 가스 압축기(23-KA-9101) 실데이터. Cognite가 공개함
- **확인한 것**
  - 접속 성공. Microsoft 계정과 Cognite Hub 등록이 필요함 (등록 안 하면 AADSTS50020 오류)
  - 약 1주 지연으로 계속 갱신되는 실데이터
  - 시계열 169개, 그중 1년치 10분 간격 데이터를 받은 태그는 179열(`c:\pump\data\`)
  - 모터 신호는 거의 완비: 권선 온도 3상, 3상 전류, 베어링 진동 4개, 냉각 공기 온도
  - 압축기 신호: 서지 방지 제어 18개, 씰 가스 35개, 성능 편차, 윤활유, 쿨러
  - 1년간 정지 8회(정지 때마다 서지 방지 동작), 모터 트립 0건
  - 코어레서 필터 차압이 3.0 → 5.5로 오르다 2026-10-29에 2.7로 떨어짐(교체로 추정)
  - 성능 편차 태그의 약 9%가 -2,147,483,648(위장 결측)
- **보류한 이유**
  - 고장 라벨이 없음
  - 모터는 어느 기계에나 있어서 특색이 없음 (팀 판단)
  - 해상 환경이고 필터실이 분리되어 있어 제철소와 연결이 약함 (팀 판단)
  - 제철소 공기압축기의 고장 통계는 공개 자료에서 찾지 못함. 서지와 부하 변동이 일반적으로 많이 언급되지만, 출처 상당수가 업체 자료

## 4. 채택 데이터: UCI 유압 시스템

- **출처:** ZeMA gGmbH 유압 실험 장치(Helwig 외, 2015), CC BY 4.0, https://archive.ics.uci.edu/dataset/447
- **구조:** 60초 부하 사이클 2,205회. 센서 17개
  - 압력 PS1~6: 100Hz
  - 모터 전력 EPS1: 100Hz
  - 유량 FS1~2: 10Hz
  - 온도 TS1~4, 진동 VS1, 냉각 효율 CE, 냉각 동력 CP, 효율 계수 SE: 1Hz
- **라벨** (`profile.txt`)

| 부품 | 등급 (정상 → 고장 직전) | 구분 난이도 | 가장 관련 높은 신호 |
|---|---|---|---|
| 쿨러 | 100 → 20 → 3 % | 쉬움 | 냉각 효율·동력 (상관 0.94) |
| 펌프 내부 누유 | 0 → 1 → 2 | 중간 | 효율 계수, 유량 FS1 (0.85) |
| 밸브 응답 | 100 → 90 → 80 → 73 % | 어려움 | 효율 계수, 유량 (0.51) |
| 어큐뮬레이터 압력 | 130 → 115 → 100 → 90 bar | 가장 어려움 | 유량·압력 최댓값 (0.44) |

  - 안정 플래그: 34%(756사이클)가 "아직 안정 상태에 도달하지 않음"

- **G-1 관점의 특징**
  1. 결측 0, 중복 0. 실험실 데이터라 결측·이상치 처리 연습 거리는 적음. 대신 안정 플래그로 "정상 조업 구간 선별"을 하는 단계로 활용
  2. 시간에 따라 실제로 열화된 기록이 아니라 상태를 바꿔 가며 반복한 **설계된 실험**. 그래서 RUL 회귀보다 **등급 분류**가 맞음. G-1 27단원의 `failure_soon`처럼 "고장 직전 등급 = 1"로 이진 라벨을 만들면 같은 흐름으로 진행 가능
  3. 네 부품이 모두 정상인 사이클은 21개뿐. 이상 탐지 기준선은 **부품별 정상**으로 잡아야 함
  4. 쿨러 등급은 사이클 순서에서 3개 블록으로만 바뀜. 학습·평가 데이터를 나눌 때 순서가 섞이지 않도록 주의

- **제철소 연결 (가설이며 현장 확인 필요)**
  - 쿨러 저하 → 고온 환경에서 유온 상승 → 점도 저하, 씰 손상
  - 밸브 응답 지연 → 압연 AGC 서보 밸브 지연 → 두께 편차 (G-1 3절: 압연은 AGC 조작량을 본다)
  - 펌프 누유 → 압력 유지 실패, 효율 저하
  - 어큐뮬레이터 압력 저하 → 압력 맥동, 비상 동작용 축압 부족

## 6. 남은 결정과 할 일

### 팀 결정
- [ ] 서비스 형태: 예지 안전등 / 정비 우선순위 대시보드 / 자동 정비 리포트 / 기타
- [ ] 분석 대상 부품: 하나(예: 펌프 누유)로 시작할지, 4개를 한꺼번에 할지
- [ ] 제철소 연결 가설(4절)을 강사나 현장 경험자에게 확인받기

### 분석 순서 (G-1 기반 노트북)
1. 구조 확인과 센서 카드 작성 (G-1 2일차)
2. 안정 플래그로 구간 선별, 사이클 순서 확인
3. 탐색적 분석: 등급별 분포(boxplot), 상관(heatmap) (17~19단원)
4. 이상 탐지: 부품별 정상 기준선에 Z-score, IsolationForest (25~26단원)
5. 고장 직전 분류: 이진 라벨 + `train_test_split(stratify)` + RandomForest. 누수 방지 (27단원)
6. 평가: 혼동행렬, 재현율 우선, 임계값 조정, 비용 판단, 판단 문장 4요소 (28~29단원)
