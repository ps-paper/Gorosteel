# 가설검증

유압 시스템 4대 부품 데이터(UCI Hydraulic)에 대한 가설검정 노트북 모음입니다.
피드백 "EDA를 바탕으로 가설검정 추가 → p-값으로 최종 확인 → 정상성 확인 → 통계로만 할지 딥러닝까지 갈지 판단"에 맞춰 만들었습니다.

## 준비

- `data/processed/hyd_cycles.csv`가 저장소에 있습니다.
- `data/raw/` 원본 txt는 루트 README 3절대로 각자 내려받습니다. H03, H11, H12, H13, 99번 노트북이 원본을 읽습니다.
- 패키지: `ml/requirements.txt`에 더해 `statsmodels`가 필요합니다. 99번은 `torch`(CPU 버전이면 충분)도 필요합니다.

## 실행 순서

1. `H01` ~ `H15`는 서로 독립이라 아무 순서로나 실행할 수 있습니다. 각 노트북은 판정을 `results/HXX.json`에 저장합니다.
2. 마지막으로 `99_종합판정_통계vs딥러닝`을 실행합니다. 15개 결과를 모아 최종표를 만들고, 1D-CNN 비교 실험을 합니다(CPU 10~15분).

## 노트북 구성 (모든 가설 공통)

1. EDA 시각화
2. 기술통계
3. 가정 확인 (정규성·등분산 등) → 검정 방법 선택
4. 정상성 확인 (ADF + KPSS, 자기상관 그림). 범주형 가설은 시간 배치 확인으로 대신함
5. 가설검정 (p-값, 여러 번이면 Holm 보정)
6. 사후검정·효과 크기
7. 재확인 (50사이클 블록 평균 등, 자기상관 대응)
8. 최종 판정 (표 + results 저장)
9. 해석과 결정

기준: 유의수준 0.05(미리 고정). 표본이 2,205개로 커서 작은 차이도 유의하게 나오므로 **결론은 효과 크기와 함께** 냅니다.

## 가설 목록

| 노트북 | 질문 | 검정 |
|---|---|---|
| H01 | 냉각기 상태에 따라 냉각 효율이 다른가 | Kruskal-Wallis, Dunn |
| H02 | 펌프 누설에 따라 유량·효율 계수가 다른가 | Kruskal-Wallis, Dunn |
| H03 | 밸브 상태에 따라 특정 구간의 압력이 다른가 | 구간 12개 Kruskal-Wallis |
| H04 | 온도를 통제해도 축압기 효과가 남는가 | ANCOVA |
| H05 | 온도(와 전체 특징 66개)는 정상 시계열인가 | ADF + KPSS |
| H06 | 앞뒤 사이클끼리 닮았는가 (자기상관) | Ljung-Box |
| H07 | 부품 상태가 같아도 데이터가 시간에 따라 변하는가 (드리프트) | KS (부품 상태 고정 구간) |
| H08 | 냉각기·축압기에는 LDA가 RF보다 나은가 | McNemar |
| H09 | 불안정 사이클이 특정 부품 상태에 몰려 있는가 | 카이제곱 |
| H10 | 정규분포·등분산인가 (검정 방법 선택 근거) | D'Agostino K², Levene |
| H11 | PS4 위장 결측이 냉각기와 관련 있는가 (누수) | 카이제곱 |
| H12 | FS1 포화 횟수가 부품 상태와 관련 있는가 | Kruskal-Wallis |
| H13 | 모터 전력 주파수 대역이 펌프 누설에 따라 다른가 | 대역 6개 Kruskal-Wallis |
| H14 | 부품 상태끼리 관련 있게 배치되었는가 | 카이제곱 |
| H15 | 센서끼리 정보가 겹치는가 (다중공선성) | Spearman, VIF |
| 99 | 최종표 + 통계 vs 딥러닝 | McNemar (1D-CNN vs LDA·RF) |

## 주의

- 지금 결과는 **특징 v1**(사이클 통계) 기준입니다. 특징 v2 확정(WBS 4.1.1) 후 H03, H08, H13, 99를 다시 실행합니다.
- `common.py`에는 데이터 읽기, Dunn 검정, 정상성 표 같은 반복 함수만 있습니다. 검정 자체는 각 노트북에 그대로 보이게 두었습니다.
